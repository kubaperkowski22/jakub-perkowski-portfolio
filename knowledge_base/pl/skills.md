# Umiejętności

## Python i inżynieria oprogramowania

Python jest jednym z głównych języków wykorzystywanych w mojej pracy i projektach. Mam doświadczenie w tworzeniu aplikacji i automatyzacji z użyciem Pythona oraz ekosystemu .NET. W PLUM pracowałem również z GitLab CI/CD, Git i Jira w zespole Scrum.

W aktualnym portfolio wykorzystuję FastAPI, Jinja2, HTML, CSS i JavaScript. Zaimplementowałem routing, obsługę dwóch języków, responsywną nawigację oraz strony projektów generowane z danych JSON. Jestem w trakcie nauki i rozwijania kolejnych elementów aplikacji AI.

## Machine learning i deep learning

Umiejętności wymienione w moim CV obejmują Machine Learning, Deep Learning, Neural Networks, PyTorch, TensorFlow, scikit-learn, NumPy, pandas i Matplotlib.

Najważniejszym praktycznym przykładem jest praca magisterska, w której implementowałem DeepSurv, DeepHit i własne warianty z FeatureAttention. Przygotowywałem dane, trenowałem sieci oraz porównywałem wyniki za pomocą metryk analizy przeżycia. Tensorflow był przeze mnie wielokrotnie wykorzystywany do tworzenia modeli uczenia maszynowego (Machine Learning) i głębokiego (Deep Learning). W projekcie News Extractor wykorzystałem TF-IDF oraz klasyfikatory SVM, Naive Bayes i Random Forest, a także spaCy do analizy języka polskiego.

## LLM i integracja API

W DiagnoseMe integrowałem model językowy przez OpenAI API. Projekt obejmował przygotowanie prompta na podstawie uporządkowanych danych użytkownika, wysłanie żądania i wykorzystanie odpowiedzi w aplikacji desktopowej.

Obecnie rozwijam AI Portfolio Assistant, którego planowana architektura obejmuje RAG, embeddings, wyszukiwanie wektorowe i ewaluację. Elementy te nie są jeszcze przedstawiane jako ukończone doświadczenie produkcyjne. W samoocenie przekazanej podczas planowania projektu określiłem znajomość LLM API jako dobrą, a RAG, embeddings i vector databases jako obszary do nauki.

## Bazy danych, API i narzędzia

W CV wymieniam SQL, bazy danych, tworzenie REST API, C# (.NET), Git, GitHub, GitLab oraz potoki CI/CD. Przykładem pracy z bazą jest Azure SQL i Entity Framework Core w DiagnoseMe. Przykładami integracji API są DiagnoseMe oraz rozwijane portfolio FastAPI.

W CV znajdują się również C i C++, od których zacząłem swoją naukę programowania lata temu. Potrafię posługiwać się tymi językami, ale nie jestem ekspertem w tej dziedzinie.

## Aktualnie rozwijane kompetencje

Planowane kolejne etapy AI Portfolio Assistant obejmują PostgreSQL i pgvector, SQLAlchemy, Pydantic, pytest, Docker, GitHub Actions, integrację API modeli i embeddings oraz ewaluację RAG. Będę aktualizował ten dokument po rzeczywistym zaimplementowaniu i przetestowaniu tych elementów.
