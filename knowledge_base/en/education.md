### Master's thesis

**Deep Neural Networks in Survival Analysis**

The thesis involved implementing and comparing DeepSurv and DeepHit with two custom variants extended with FeatureAttention. The research covered seven oncology datasets, ten training runs per model on each dataset, and evaluation using the C-index and Integrated Brier Score. The primary objective of the module was to make relative input-feature weighting analyzable, with an additional investigation of its effect on predictive performance.

A detailed description of the methodology, results, and limitations is available at `/projekty/survival-analysis` and in the project's separate knowledge-base document.

### Engineering thesis

**DiagnoseMe**

The project involved creating a WPF desktop application that used the OpenAI API to generate responses based on selected symptoms and follow-up questions. The application used an Azure SQL database and included user management, history, and appointment features. It was an academic prototype, not a clinically validated diagnostic tool.

Details: `/projekty/diagnose-me`.
